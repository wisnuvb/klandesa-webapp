# Foto tim (`public/team/`)

Letakkan foto founder di folder ini dengan nama yang konsisten, misalnya `wisnu-saputro.jpg`.

Foto ditampilkan persegi (kartu di halaman `/tim`), jadi disarankan potret **1:1** sekitar **800×800px**, format JPG atau WebP, ukuran file di bawah ~200KB agar halaman tetap ringan.

Setelah file ada, isi field `image` di `lib/team/founders.ts` dengan path publik, misalnya `"/team/wisnu-saputro.jpg"`.
