# Foto tim (`public/team/`)

Letakkan foto founder di folder ini dengan nama yang konsisten, misalnya:

- `wisnu.jpg`
- `boediman.jpg`
- `krina.jpg`

Disarankan potret **4:5** atau vertikal, sekitar **800×1000px**, format JPG atau WebP, ukuran file di bawah ~200KB agar halaman tetap ringan.

Setelah file ada, isi field `image` di `lib/team/founders.ts` dengan path publik, misalnya `"/team/wisnu.jpg"`.
